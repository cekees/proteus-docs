site: release docs at `/` (from `gh-pages`), JupyterLite at `/lite/`, nightly at
`/main/`. See cekees/fleet `notes/docs-hubs-plan.md`. Prototype on this fork
before anything changes on erdc/proteus-docs or proteustoolkit.org.
